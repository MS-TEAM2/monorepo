# M4 월세 손익 계산

- Notion 기획: https://app.notion.com/p/423e81557ede81e69889c29103e8b04e
- 에픽: SCRUM-82
- 상태: 승인됨

## 문제

예비창업자에게는 감당 가능한 월세의 기준이 없다. 한 달에 얼마를 팔아야 하는지 모른 채 계약하게 된다.

대상 사용자: 월세 조건을 검토하는 서울 외식업 예비창업자. 모바일 우선 웹.

## 사용자 시나리오

1. 탐색 정보 → 월 비용 → 초기 비용의 3단계로 값을 입력한다.
2. 진단 결과에서 손익분기 매출을 본다. 예상 월매출을 넣었다면 월손익과 감당 가능한 월세도 본다.
3. 월세 슬라이더를 움직여 손익 변화를 확인한다.

## 요구사항

- [ ] R1. 월세·인건비·기타 고정비·변동비율은 필수로, 나머지는 기획서 S04 규칙으로 검증한다.
- [ ] R2. 화면은 만원 단위로 입력받고 API에는 원 단위 정수로 보낸다.
- [ ] R3. 예시값에는 `예시값`을 표시하고 사용자가 확인해야 다음으로 간다.
- [ ] R4. 손익분기 매출, 예상 월손익, 감당 가능한 월세를 기획서 7번 산식으로 계산한다.
- [ ] R5. 예상 월매출이 없으면 손익분기만 계산하고 월손익·감당 가능한 월세·예상 손실은 표시하지 않는다.
- [ ] R6. 감당 가능한 월세가 음수면 `월세가 없어도 적자`로 표시하고, 이 값이 시세가 아님을 알린다.
- [ ] R7. 슬라이더 옆에 월세를 움직여도 생존확률은 바뀌지 않음을 적는다.
- [ ] R8. 수치는 코드가 계산하고 LLM은 계산하지 않는다.

## 범위 밖

- 주변 월세 시세·적정 월세
- 추정매출을 예상 월매출로 자동 입력
- 계약서 조건 반영과 예상 손실(M6)

## 성공 기준

- 공통 시험 사례에서 화면과 API 값 일치 100%
- 고정비 700만 원·변동비율 40%일 때 약 1,167만 원, 월세만 270만 원으로 바꾸면 1,200만 원
- 진단 API p95 3초 이내(목표)

## 확인 필요

- 결정(2026-11-25): 관리비는 선택 입력으로 한다.
- 결정(2026-11-25): 월세는 1원 이상으로 한다.
- 결정(2026-11-25): 포함 금액이면 공급가로 환산하고 일반과세자 기준임을 표시한다.
