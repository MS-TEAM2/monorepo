# M3 생존 진단

- Notion 기획: https://app.notion.com/p/423e81557ede811c9494c09d90365ba2
- 에픽: SCRUM-81
- 상태: 승인됨

## 문제

예비창업자는 고른 위치에서 같은 업종이 얼마나 버티는지 알기 어렵다. 유동인구가 많다는 이유만으로 계약하면 업종의 실제 생존 가능성을 놓칠 수 있다.

대상 사용자: 위치와 업종을 정하고 계약을 검토하는 서울 외식업 예비창업자. 모바일 우선 웹.

## 사용자 시나리오

1. 상권 요약이나 홈에서 진단을 시작하고 위치, 업종 1개, 면적(선택)을 확인한다.
2. 진단을 실행하면 1·2·3년 생존확률과 범위, 서울 같은 업종 기준선을 본다.
3. 요인과 한계를 확인하고 손익 또는 계약서 확인으로 이동한다.

## 요구사항

- [ ] R1. 12·24·36개월 생존확률, 범위, 산출 방법, 서울 같은 업종 기준선을 함께 보여 준다.
- [ ] R2. 위험·긍정 요인을 각 최대 3개 보여 주고 인과관계가 아님을 표시한다.
- [ ] R3. 특정 점포의 확정 예측이 아님을 표시하고 `계약하세요`, `하지 마세요`라고 단정하지 않는다.
- [ ] R4. 월세는 학습과 추론에 쓰지 않는다. 월세를 바꿔도 생존확률은 바뀌지 않는다.
- [ ] R5. 업종별 Kaplan-Meier 기준선을 먼저 제공한다. 모델이 교체 조건을 넘지 못하거나 사용할 수 없으면 기준선을 쓰고 그 사실을 표시한다.
- [ ] R6. 1년 모델은 업종·면적·자리 이력의 로지스틱을 우선한다. 면적이 없거나 팝업성 조건에 해당하는 위치, 모델 미채택이면 업종 기준선을 쓰고 서울·업종 단위 결과임을 밝힌다.
- [ ] R7. 근거가 부족하면 확률 대신 `자료 부족`을 표시하고 손익은 그대로 제공한다.
- [ ] R8. 학습에는 개업일보다 앞선 자료만 쓰고, 동 분리·연도 순서로 검증하며 2025년 시험은 한 번만 한다. 데이터 버전과 실측 지표를 ML 실험 DB에 기록한다.

## 범위 밖

- 특정 점포의 생존 확정 예측
- 월세가 생존확률에 미치는 영향
- 대안 동네(P1-5, 보류)

## 성공 기준

- ML 모델은 업종 기준선 대비 Brier score 5% 이상 개선. 보정이 나빠지지 않을 때만 교체
- 진단 API p95 3초 이내(목표)
- 월세 변경 전후 생존확률 차이 0
