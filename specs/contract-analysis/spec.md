# M5 계약서 분석

- Notion 기획: https://app.notion.com/p/423e81557ede81fab024ffc137cab840
- 에픽: SCRUM-83
- 상태: 승인됨

## 문제

예비창업자는 계약서 설명을 중개사에게 의존한다. 원상복구·관리비·중도해지 조건을 놓친 채 계약할 수 있다.

대상 사용자: 상가 임대차계약서를 받아 검토하는 서울 외식업 예비창업자. 앱과 모바일 웹에서 촬영하거나 파일을 올린다.

## 사용자 시나리오

1. 동의 문구를 확인하고 계약서를 촬영하거나 선택한다.
2. 업로드 → 글자 인식 → 개인정보 가리기 → 조항 분석 → 원본 삭제의 진행 상태를 본다.
3. 추출값을 원문 근거와 비교해 확인하거나 고친다.
4. 위험 특약과 중개사에게 물을 질문을 본다.

## 요구사항

- [ ] R1. 원본 처리 방식, 외부 AI 서비스 사용, OCR의 24시간 보관과 삭제 시점에 동의해야 올릴 수 있다.
- [ ] R2. JPG·PNG·PDF를 파일당 10MB, 합계 20MB, 최대 10쪽까지 받고 카메라 촬영을 지원한다.
- [ ] R3. 보증금, 월세, 관리비, 부가세, 계약 기간, 인상률, 중도해지, 원상복구를 원문 근거·신뢰도와 함께 보여 준다.
- [ ] R4. 신뢰도가 낮은 값은 빈칸으로 두고 직접 입력받는다.
- [ ] R5. R01–R08 위험 특약의 원문, 이유, 확인할 내용, 질문을 보여 준다. 관련 법령은 원문 대조 후에만, 수정 제안은 법률 확인 후에만 표시한다.
- [ ] R6. 마스킹한 글만 LLM에 보내고 문서 속 지시는 따르지 않는다. 마스킹에 실패하면 분석을 중단한다.
- [ ] R7. 성공·실패·취소 모두 Blob 원본과 OCR 보관분을 삭제한다. 10분을 넘긴 작업은 실패 처리하고 재시도를 안내한다.
- [ ] R8. 실패하면 사유와 다시 찍는 방법을 보여 준다.
- [ ] R9. 법률 자문이 아닌 검토 보조임을 표시하고 위법이라고 단정하지 않는다.
- [ ] R10. 원본 미리보기는 브라우저 안에서만 유지하고 계약서 내용을 로그에 남기지 않는다.

## 범위 밖

- 법률 자문과 위법 판정
- AI Search를 이용한 법령 검색
- 실제 계약서를 이용한 개발·평가

## 성공 기준

- 가상 계약서에서 위험 특약 재현율 85% 이상. 정밀도도 함께 보고
- 사용자 확인 전 손익 반영 0건
- 10쪽 계약서 분석 60초 이내(목표)
- 성공·실패·취소·컨테이너 종료 시험 모두에서 원본과 OCR 보관분 삭제 확인
- 이름·주민등록번호·전화·주소·계좌의 마스킹 누락률 보고. 누락 확인 시 LLM 전송 중단
- 월세·보증금·기간의 필드별 추출 정확도 보고. 목표값은 첫 평가 후 확정
