# M10 소셜 로그인·접근 제한

- Notion 기획: https://app.notion.com/p/423e81557ede81f9a0a3ce7abde8e4f6
- 에픽: SCRUM-170
- 상태: 승인됨

## 문제

예비창업자의 진단과 계약 정보는 익명 세션에만 있어 다른 기기에서 이어 볼 수 없고 브라우저 데이터를 지우면 잃는다. 로그인 전에는 상권 탐색을 가볍게 보고, 개인 정보가 쌓이는 기능은 본인 계정으로 안전하게 써야 한다.

대상 사용자: 서울 외식업 예비창업자. 모바일 우선 웹과 앱(웹뷰).

## 사용자 시나리오

1. 로그인하지 않은 사용자가 매장 지도·목록과 반경의 간단한 요약을 본다.
2. 잠긴 기능을 누르면 로그인 화면으로 가고, 구글이나 카카오로 로그인한다.
3. 로그인 후 원래 화면과 선택한 위치·반경·업종으로 돌아와 이어서 쓴다.
4. S11에서 로그아웃하거나 회원 탈퇴한다.

## 요구사항

- [ ] R1. 구글과 카카오 소셜 로그인을 제공한다.
- [ ] R2. 로그인 전에는 S01, S02의 매장 지도·목록, S03의 반경 지표(같은 업종 매장 수, 개업·폐업 수), S12 창업 가이드, S11·S14 읽기만 제공한다.
- [ ] R3. S03의 행정동 지표와 S04–S10, 직접 그리기는 로그인해야 쓸 수 있다. 서버 API도 로그인을 검사한다. 2026-11-27(SCRUM-193)부터 창업 가이드(S12)와 지원정책도 로그인 필요로 바꿨다(Notion 기획서 2·14장 수정과 팀 합의 필요). 로그아웃 상태로 이 기능들을 누르면 이유를 알리는 안내 창을 먼저 띄운다.
- [ ] R4. 로그인 후 원래 화면과 선택값으로 돌아온다. 취소·실패·만료를 안내하고 다시 시도하게 한다.
- [ ] R5. 진단·계약·저장 자료는 로그인한 사용자에게 속하고 다른 사용자는 볼 수 없다(404).
- [ ] R6. 이메일·이름·사진과 공급자 토큰을 저장하지 않는다. 공급자별 식별값만 저장하고 구글·카카오 계정은 합치지 않는다.
- [ ] R7. 로그인 상태는 30일 유지하며 로그아웃하면 즉시 끝난다.
- [ ] R8. 처음 로그인할 때 약관·개인정보 처리방침 동의와 버전을 기록하고 만 14세 이상임을 확인받는다.
- [ ] R9. 회원 탈퇴하면 모든 로그인을 즉시 끝내고 계정과 자료를 삭제한다. 구글·카카오 연결 해제 방법을 안내한다.
- [ ] R10. iPhone 앱에서도 시스템 인증 브라우저로 두 로그인을 쓰고 돌아온다. 지원하지 않는 구버전 앱에는 업데이트를 안내한다.

## 범위 밖

- 이메일·비밀번호 가입, 다른 소셜 로그인, 계정 합치기
- 관리자 기능, 결제
- 앱 스토어 출시와 심사, Android 실기기 확인
- 자료 삭제의 세부 동작(M7)

## 성공 기준

- 구글·카카오 각각 웹과 iPhone 실기기에서 로그인 후 원래 화면 복귀
- 로그인 없이 보호된 API 호출 시 401 100%
- 로그인 전 응답에 행정동 지표 포함 0건, 다른 사용자 자료 노출 0건
- 로그아웃·탈퇴 뒤 이전 토큰 사용 성공 0건
- DB·로그에 공급자 토큰·이메일·이름 저장 0건
