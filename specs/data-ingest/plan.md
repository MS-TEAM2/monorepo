# M9 데이터 수집·한계 안내 — 구현 계획

스펙: `./spec.md`

## 접근 방식

원천별 수집을 다시 실행해도 안전하게 만들고 수집 이력을 남긴다. 실패하면 직전 성공본을 유지한다. 데이터 확인 1–3을 먼저 판정해 다른 기능의 축소 여부를 정한다.

## API 변경

추가: `GET /data-status`(A24)

기본 경로는 `/api/v1`이다. 백엔드 스키마에서 `docs/api/openapi.yaml`과 프론트 생성 타입을 갱신해 같은 PR에 넣는다.

## 데이터·모델

일반·휴게음식점·제과점 인허가, 점포·추정매출·길단위인구, 행정동 경계. 행정동 결합률 95%·업종 매핑률 90% 이상.
