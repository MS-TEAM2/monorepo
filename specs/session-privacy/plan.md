# M7 익명 세션·내 데이터 삭제 — 구현 계획

스펙: `./spec.md`

## 접근 방식

토큰은 해시만 저장하고 모든 사용자 자료를 세션 소유로 묶는다. 삭제는 요청을 먼저 기록해 조회를 막고, 분석 취소와 원본 삭제 뒤 행을 지운다. 남은 삭제는 정리 작업이 재시도한다.

## API 변경

추가: `POST /sessions`(A01), `DELETE /sessions/me`(A02), `DELETE /diagnoses/{id}`(A12), `DELETE /contracts/{id}`(A19)

기본 경로는 `/api/v1`이다. 백엔드 스키마에서 `docs/api/openapi.yaml`과 프론트 생성 타입을 갱신해 같은 PR에 넣는다.
