# M7 내 데이터 삭제

- Notion 기획: https://app.notion.com/p/423e81557ede8100b0b8d24a1063553b
- 에픽: SCRUM-85
- 상태: 승인됨

## 문제

예비창업자는 로그인한 계정에 진단과 계약 정보를 맡긴다. 자신의 자료가 다른 사람에게 보이지 않고, 원할 때 모두 지울 수 있어야 한다.

대상 사용자: 진단이나 계약서 분석을 이용한 예비창업자. 모바일 우선 웹.

## 사용자 시나리오

1. 로그인한 사용자의 진단이 계정에 30일 동안 보관된다.
2. S11에서 `내 데이터 모두 삭제`를 누르면 완료 또는 처리 중 상태를 본다.
3. S08에서 계약 하나를 삭제하면 그 계약과 계산을 다시 조회할 수 없다.

## 요구사항

- [ ] R1. 진단·계약 자료를 로그인한 사용자에게 속하게 하고 30일 보관한다. 로그인은 M10이 맡는다.
- [ ] R2. 다른 사용자의 자료는 조회할 수 없다(404).
- [ ] R3. 모두 삭제하면 진단, 계산, 계약, 저장한 자리, 남은 원본과 OCR 보관분을 삭제한다. 계정은 유지한다.
- [ ] R4. 계약 삭제는 조건, 근거, 위험 결과, 이 계약으로 만든 계산을 삭제한다.
- [ ] R5. 요청 즉시 자료 조회를 막고 처리 중인 분석을 취소한다.
- [ ] R6. 삭제 완료 또는 `삭제 처리 중`을 표시하고, 남은 삭제는 정리 작업이 재시도한다.
- [ ] R7. 토큰을 로그에 남기지 않는다.

## 범위 밖

- 로그인과 회원 탈퇴(M10)
- 저장한 자리의 개별 삭제(P1-3)
- 공공데이터와 모델 버전 삭제

## 성공 기준

- 모두 삭제한 뒤 이전 자료 조회 성공 0건
- 계약 삭제 뒤 조회 시 404 100%
- 분석 중 삭제한 결과의 저장 0건
