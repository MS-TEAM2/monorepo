# M6 계약 조건 반영 — 구현 계획

스펙: `./spec.md`

## 접근 방식

확인한 조건만 진단 입력 위에 덮어 손익과 예상 손실을 다시 계산한다. before에는 직접 입력한 종료 값만, after에는 확인한 계약값도 적용한다.

## 영역별 변경

| --- | --- |
| BE | 예상 손실 계산, A18 |
| FE | S08 전후 비교, 질문 복사·공유 |
| AI | 없음 |
