# M2 상권 요약 — 구현 계획

스펙: `./spec.md`

## 접근 방식

반경 지표는 인허가로, 행정동 지표는 상권 자료로 계산해 한 응답에 단위를 나눠 담는다. 작은 값과 확인되지 않은 매출은 서버에서 내려보내지 않는다.

## 영역별 변경

| 영역 | 변경 내용 |
| --- | --- |
| BE | A07 스키마, 반경·행정동 집계 |
| FE | S03 하단 시트·왼쪽 패널 |
| AI | 매출 단위와 유동인구 최신 분기 확인 |

## API 변경

추가: `GET /areas/summary`(A07)

기본 경로는 `/api/v1`이다. 백엔드 스키마에서 `docs/api/openapi.yaml`과 프론트 생성 타입을 갱신해 같은 PR에 넣는다.

## 데이터·모델

`stores`, `region_population`, `region_store_stats`, `region_sales`, 행정동 코드 매핑. 행정동 결합률 95% 이상.
