# M1 주변 상권 지도 — 구현 계획

스펙: `./spec.md`

## 접근 방식

주소·현재 위치로 중심을 정하고 인허가 매장을 반경으로 조회한다. 행정동은 경계로 판정하고 주소 검색은 브라우저의 네이버지도가 처리한다. PostGIS가 승인되지 않으면 좌표 범위와 거리 계산으로 반경 조회를 먼저 제공한다.

## 영역별 변경

| 영역 | 변경 내용 |
| --- | --- |
| BE | A03·A04·A05 스키마와 라우트 |
| FE | S01 홈, S02 탐색(지도·필터·목록·예외) |
| AI | 외식 9종 업태 매핑표 |

## API 변경

추가: `GET /categories`(A03), `GET /regions/resolve`(A04), `GET /stores`(A05)

기본 경로는 `/api/v1`이다. 백엔드 스키마에서 `docs/api/openapi.yaml`과 프론트 생성 타입을 갱신해 같은 PR에 넣는다.

## 데이터·모델

data-ingest의 `stores`·`regions`와 매핑표. 업종 매핑률 90% 이상(2021년 이후 개업·현재 영업 매장 각각).

## 위험과 대응

- 위험: PostGIS 승인 지연 → 대응: 좌표 범위와 거리 계산
- 위험: 일반음식점 최신성 미달 → 대응: 기획서 18번 대안
