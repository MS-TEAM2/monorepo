# M1 주변 상권 지도

- Notion 기획: https://app.notion.com/p/423e81557ede81eea555e4c652b49498
- 에픽: SCRUM-79
- 상태: 승인됨

## 문제

예비창업자는 지도와 유동인구만 보고 자리를 고르기 쉽다. 사람이 많은 것과 업종이 버티는 것을 혼동하고, 고른 자리 주변에 같은 업종이 얼마나 있는지 파악하기 어렵다.

대상 사용자: 계약을 앞둔 서울 외식업 예비창업자. 모바일 우선 웹이며 앱은 같은 화면을 웹뷰로 띄운다.

## 사용자 시나리오

1. 홈에서 `주변 상권 보기`를 누르면 탐색 화면으로 간다.
2. 주소를 검색하거나 현재 위치를 쓰거나 지도를 길게 누르면 중심 핀이 바뀐다.
3. 업종과 반경을 고르면 조건에 맞는 영업 중 매장을 지도와 목록으로 본다.
4. `이 자리 요약 보기`를 누르면 상권 요약으로 이동한다.

## 요구사항

- [ ] R1. 홈에 서비스 소개, `주변 상권 보기`, `정해 둔 자리 진단하기`를 두고 서울·외식 9종만 지원함을 표시한다. 최근 진단이 있으면 이어 보기를 보여 준다.
- [ ] R2. 주소 검색이나 현재 위치에서 좌표와 행정동을 얻는다.
- [ ] R3. 외식 9종(복수 선택)과 반경 150m·300m·500m·1km(기본 500m)로 거른다. 업종을 고르지 않으면 9종 전체를 조회한다.
- [ ] R4. 인허가상 영업 중인 매장의 상호·업종·인허가 연도만 보여 준다. 폐업 매장은 개별로 표시하지 않는다.
- [ ] R5. 최대 1,000곳을 표시하고, 넘으면 표시 건수·전체 건수·필터 안내를 보여 준다.
- [ ] R6. 지도를 움직이면 자동 조회 없이 `이 지역에서 다시 찾기`를 보여 준다.
- [ ] R7. 매장 목록만으로도 같은 내용을 보고 상권 요약까지 갈 수 있다.
- [ ] R8. 조회 중, 결과 없음, 1,000곳 초과, 위치 권한 거부, 서울 밖, 지도 로딩 실패를 기획서 S02대로 처리한다.
- [ ] R9. 좌표가 없는 매장은 지도와 반경 집계에서 뺀다. 전화번호와 대표자 정보는 저장하지 않는다.
- [ ] R10. 업태는 외식 9종으로 매핑하고 맞지 않는 업태는 미분류로 남겨 제외한다.

## 범위 밖

- 서울 밖, 외식 9종 외 업종, 매장별 영업시간
- 직접 그린 영역 조회(P1-4)

## 성공 기준

- 탐색 API p95 1초 이내(목표)
- 업종 매핑률 90% 이상
- 조건에 맞지 않는 매장 표시 0건
- 375px 화면에서 검색부터 요약까지 동작, 터치 영역 44×44px 이상
