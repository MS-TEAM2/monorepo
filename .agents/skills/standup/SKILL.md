# standup — 데일리 스탠드업

## 순서

1. **기간 정하기**: 직전 근무일 0시부터 지금까지. 월요일이면 금요일부터 본다.
2. **한 일 모으기**
   - `git log --author=<본인> --since=<기간>`으로 본인 커밋
   - GitHub 도구(`gh pr list --author @me --state all`)로 본인 PR의 생성·머지·리뷰 상태
   - Jira 도구로 본인에게 할당된 이슈 중 기간 안에 상태가 바뀐 것
3. **오늘 할 일**: Jira에서 본인의 In Progress와 다음 순서 To Do 이슈를 본다. 확실하지 않으면 사용자에게 묻는다.
4. **막힌 점**: 리뷰 대기 중인 PR, 실패한 CI, 선행 티켓 대기 등을 찾는다. 없으면 "없음".
5. **초안 확인**: 아래 양식으로 보여 주고 사용자가 고칠 기회를 준다.
6. **게시**: 승인받으면 Slack 도구로 `#standup` 채널에 올린다. Slack 도구가 연결돼 있지 않으면 복사해서 붙일 수 있게 글만 출력한다.

## 양식

```
*<이름> · <날짜>*
*어제* 
• SCRUM-12 로그인 API 구현, PR #34 리뷰 요청
*오늘*
• SCRUM-15 토큰 갱신
*막힌 점*
• 없음
```

## 규칙

- 항목마다 이슈 키를 붙인다. 한 항목은 한 줄.
- 하지 않은 일을 한 것처럼 쓰지 않는다. 기록에 없는 일은 사용자에게 물어서 넣는다.
