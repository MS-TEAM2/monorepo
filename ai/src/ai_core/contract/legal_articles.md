# 법령 원문 대조표 (SCRUM-140)

표는 `legal_articles.csv` 하나다. 위험 특약(R01–R08)과 관계된 법령 조문·판례의 시행일, 출처, 대조일, 상태를 담는다.

**법률 검토 전이다.** 원문 대조는 AI(Claude)가 했고, 규칙과의 연결은 D2가 정리했다. 법률 전문가의 확인을 받지 않았다.

## 사용 원칙

- 화면 후보는 `status`가 `대조 완료`이고 `rule_ids`가 있는 행뿐이다.
- `미사용` 행은 코드·프롬프트·화면에 쓰지 않는다.
- 화면 후보라고 모두 보여 주지 않는다. 배경 설명에 가까운 조문(예: R01의 감염병예방법, R04의 차임 증감 조문)도 연결되어 있으므로 규칙마다 보여 줄 조문을 따로 고른다.
- 법률 검토 담당자가 확인하기 전에는 수정 제안을 보여 주지 않는다(기획서 R5).
- 환산보증금에 따라 적용되는 조문이 다르므로 화면에서 위법이라고 단정하지 않는다.

## 열

| 열 | 뜻 |
| --- | --- |
| kind | `statute`(법령 조문), `case_law`(판례) |
| name | 법령 약칭과 조, 또는 사건번호. 상임법 = 상가건물 임대차보호법 |
| title | 법령은 조문 제목, 판례는 요지의 요약 |
| rule_ids | 연결한 위험 특약 규칙(`;`로 구분). 비어 있으면 규칙에 연결하지 않음 |
| case_nos | 아래 사례 번호(`;`로 구분) |
| effective_date | 대조에 쓴 시행본의 날짜. 판례는 선고일. 조문별 신설일·적용례와 다를 수 있다 |
| source_url | 국가법령정보센터의 현행 본문 |
| checked_on | 원문을 대조한 날짜. 미사용 행은 비움 |
| status | `대조 완료`, `미사용` |
| note | 적용 범위나 미사용 이유 |

## 대조 방법

- 2026-11-26에 국가법령정보센터에서 내려받은 법령·판례 PDF의 본문과 대조했다. PDF는 레포에 넣지 않았다.
- `source_url`은 같은 날 모두 열리고 페이지 제목이 대상과 맞는 것을 확인했다. 링크는 현행 본문이라 개정되면 대조한 시행본과 달라진다. 갱신할 때는 시행일을 먼저 비교한다.

## 대조하며 확인한 점

1. **관리비 내역 제공(상임법 19조의2, 시행령 8조):** 2026-05-12 이후 체결·갱신한 계약부터 적용한다(부칙 2조). 2조③ 목록에 19조의2가 없어 문언상 환산보증금 초과 계약에는 적용되지 않는다.
2. **중도해지(민법 636조):** 기간을 정한 임대차는 해지권을 보류해야 기간 중에 해지할 수 있다.
3. **강행규정 범위(민법 652조):** 623조(수선의무)와 626조(비용상환)는 목록에 없고, 646조(부속물매수청구권)는 있다.
4. **상임법 11조의2의 참조:** '감염병예방법 49조①2호의2의 운영시간 제한'을 적고 있으나, 대조한 현행 감염병예방법의 해당 호에는 그 내용이 없다. 법률 검토 때 확인한다.
5. **옥외광고물법 3조⑦:** 간판 제한 특약이 건물의 간판표시계획을 따르는 것일 수 있다.

## 미사용 항목

이자 최고이율 규정은 내려받은 PDF에 본문이 없었고, 소송촉진법의 법정이율 규정은 대조하지 않았다. 둘 다 연체이자·지연손해금에 관한 것으로 R01–R08 밖이라 추가 확인 없이 미사용으로 둔다.
